🚀 COMO USAR
═════════════════════════════════════════════════════════════════════════════

1️⃣  SETUP INICIAL (Local)
   ┌─────────────────────────────────────────────────────────────────┐
   $ chmod +x setup.sh
   $ ./setup.sh
   │
   │ Isso fará:
   │ • Criar ambiente virtual
   │ • Instalar dependências
   │ • Criar estrutura de diretórios
   │ • Executar testes de configuração
   │
   $ nano .env                    # Adicionar GROQ_API_KEY
   └─────────────────────────────────────────────────────────────────┘

2️⃣  PREPARAR DADOS
   ┌─────────────────────────────────────────────────────────────────┐
   $ cp /caminho/para/seus/*.pdf pdfs/
   $ python -m app.ingest ingest  # Ingere e indexa
   $ python -m app.ingest status  # Verifica banco
   └─────────────────────────────────────────────────────────────────┘

3️⃣  EXECUTAR SERVIDOR
   ┌─────────────────────────────────────────────────────────────────┐
   # Desenvolvimento
   $ uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
   
   # Produção
   $ uvicorn app.main:app --host 0.0.0.0 --port 8000
   
   # Com Render (automático)
   $ uvicorn app.main:app --host 0.0.0.0 --port $PORT
   └─────────────────────────────────────────────────────────────────┘

4️⃣  TESTAR API
   ┌─────────────────────────────────────────────────────────────────┐
   # Suite de testes
   $ python test_api.py
   
   # Modo interativo
   $ python test_api.py -i
   
   # Query específica
   $ python test_api.py -q "O que é 6G?"
   
   # Com verbose
   $ python test_api.py -v
   └─────────────────────────────────────────────────────────────────┘

5️⃣  ACESSAR API
   ┌─────────────────────────────────────────────────────────────────┐
   • Swagger UI: http://localhost:8000/docs
   • ReDoc:      http://localhost:8000/redoc
   • Health:     http://localhost:8000/health
   │
   # Exemplo com curl
   $ curl -X POST http://localhost:8000/query \
     -H "Content-Type: application/json" \
     -d '{"question": "O que é MIMO?"}'
   └─────────────────────────────────────────────────────────────────┘


🌐 DEPLOY NO RENDER
═════════════════════════════════════════════════════════════════════════════

1. Preparar repositório Git:
   $ git add .
   $ git commit -m "Initial commit: Metaverso 6G RAG"
   $ git push origin main

2. Conectar ao Render:
   • Criar novo Web Service
   • Conectar repositório GitHub
   • Render detecta render.yaml automaticamente

3. Configurar Variáveis de Ambiente:
   • GROQ_API_KEY = sua_chave_aqui (sync: false no render.yaml)
   • CHROMA_PERSIST_DIR = /var/data/chroma (vai com Render Disk)

4. Deploy:
   • Click em Deploy
   • Render Disk de 5GB criado automaticamente
   • App rodando em: https://seu-app-name.onrender.com

5. Usar em Produção:
   $ curl -X POST https://seu-app-name.onrender.com/query \
     -H "Content-Type: application/json" \
     -d '{"question": "Como funciona 6G?"}'

📞 TROUBLESHOOTING RÁPIDO
═════════════════════════════════════════════════════════════════════════════

Problema: "GROQ_API_KEY não está definida"
Solução: Editar .env e adicionar chave válida do https://console.groq.com

Problema: "Nenhum documento encontrado"
Solução: Verificar se PDFs estão em pdfs/ e executar ingestão

Problema: "Banco de dados não existe"
Solução: python -m app.ingest ingest

Problema: "Timeout em queries"
Solução: Reduzir INITIAL_RETRIEVAL_K em config.py

Problema: "Erro de memória no Render"
Solução: Usar instância maior ou reduzir MAX_CONTEXT_TOKENS
