- Passar arquivo para o ESP32 sem usar o terminal:
1. Baixar o software [Thonny](https://thonny.org/)
2. Conectar o ESP32 no computador via USB
3. Abrir o Thonny
4. No canto inferior direito clicar em MicroPython (ESP32) (selecionar o MicroPython (ESP32))
5. Enviar o código:
	1. File -> New 
	2. Salvar o arquivo: Save As -> Escolha “MicroPython device” (não “This computer”) -> Salve como main.py
